## 二、字段口径

| 字段 | 口径 |
|---|---|
| `source_work` | 统一写作「篇名（出处）」。底表 `source_work` 只有文献名（如《范文正公集》卷七），单用无法定位课文，故与 `title` 合成一格。 |
| `prev_sentence` / `next_sentence` | 取所在句的上下文。同一句名下多张词卡共享同一组上下文；各篇首句无前句（68 张）、末句无后句（55 张）。 |
| `term_type` / `char_count` | **按词形实际字数重算**。原 `terms_candidates` 的类型字段是 step8 标注时按当时的 term 写入的，清洗阶段改过词形（如「庭一湖」→「洞庭」），类型未同步，故不沿用源字段。 |
| `meaning_in_this_sentence` | 已剔除清洗阶段留下的切分备注（如「『庭一湖』为跨词碎片」「（本句『在洞庭一湖』）」），只留释义本体。 |
| `typical_error_mode` | 按 `sent_id` + 原始词形回连 `terms_candidates.jsonl`；清洗改过词形的走包含关系兜底，全部命中，无一条使用默认文案。 |

## 六、打分标准（供校验）

**词级**——基础分 2 分，按下列规则加减，钳制在 1–5：

| 规则 | 加减 |
|---|---|
| 命中 A 级表（全国卷高频实词＋古今异义＋通假，如 爱/走/去/布衣/爪牙/卑鄙） | +2 |
| 命中 B 级表（常考但区分度次之，如 之/其/而/谓） | +1 |
| 全库出现 ≥5 次（跨篇复现，考点概率高） | +1 |
| 双字或三字，且 term_english 长度 ≥6（英文有完整对应，说明是整体语义单元） | +1 |
| 称谓类（陛下/大王/足下/寡人/太守/有司） | 直接置 3 |
| 专名表内的人名/地名/国名（蔺相如/咸阳/赵） | 直接置 1 |
| 无辨析价值的重复词（曰/云） | 直接置 1 |

**句级**——基础分 2 分：

| 规则 | 加减 |
|---|---|
| 非一般陈述句（特殊句式/疑问/感叹） | +1 |
| 句中含 ≥1 个 4 分以上词项 | +1 |
| 句中含 ≥3 个 4 分以上词项（再叠加） | +1 |
| 净汉字数 10–30（翻译题常规长度） | +1 |
| 命中名句表（背诵默写高频；长名句取前 5 字容错，应对底表个别讹字） | +1 |
| 净汉字数 >40 | −1 |
| 净汉字数 <6 且非特殊句式且不含重点词 | −1 |
